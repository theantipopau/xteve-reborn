M3U / XMLTV → HDHomeRun tuner

One small binary turns your IPTV playlists and XMLTV guide data into an HDHomeRun tuner, so Plex DVR, Emby and Jellyfin treat IPTV like cable. A modernized, actively maintained fork of the original xTeVe — faster, safer, and kept current.

Works with Plex, Emby and Jellyfin · Linux, Windows, macOS, Docker · single binary, ~6 MB

Why Reborn

Upstream xTeVe was abandoned in 2020. This fork keeps what worked and fixes what didn't.

Streaming

Load-aware failover

Up to 3 backup URLs per channel. A healthy, idle source wins; busy sources share viewers by lowest load — the same channel from several providers no longer piles onto one account until it hits its connection limit. Idea credited to c0y0t3d3n's iptv project.

Guide

EPG that stays current

Sources are re-checked every hour with conditional requests, so guide changes reach Plex the same hour — not the next day. Only changed files are re-downloaded.

Security

Safe by default

Authentication, session fixation fixes, and none of upstream's unauthenticated paths that exposed configuration and logs.

Stability

Hangs and crashes fixed

Data races under -race, FD leaks, deadlocks and panic paths fixed — with regression tests so they stay fixed.

Docker

Container done right

Non-root by default (PUID/PGID), multi-arch images, and a real HEALTHCHECK that CI verifies reaches healthy.

Setup

Gentle onboarding

A setup wizard for first-run configuration, a rebuilt light web UI, and Jellyfin support verified by an end-to-end CI test against a real server.

Three steps to live TV

Full details and Windows/macOS binaries are in the README and the releases page.

  1. Get the latest release — a single binary for linux/amd64, linux/arm64, Windows and macOS, or pull the container. docker run -d --name xteve-reborn -p 34400:34400 -v xteve-config:/config ghcr.io/theantipopau/xteve-reborn:latest
  2. Add your sources — open the web UI, run the setup wizard, and point it at your provider's M3U playlist and XMLTV guide. http://localhost:34400/web/
  3. Point your DVR at the tuner — Plex, Emby and Jellyfin discover it like an HDHomeRun on your network. http://your-server-ip:34400
